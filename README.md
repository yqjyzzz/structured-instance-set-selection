# 拓扑感知的手术器械实例集选择

这个项目研究候选掩码如何组成最终实例集合。上游 Mask2Former 固定输出候选掩码，本仓库从候选集合开始：提取节点和成对几何特征，建立候选图，预测候选有效性、拓扑状态、竞争关系与实例数量，再由 MILP 求出最终子集。

## 项目主线

```text
手术视频帧
  → Mask2Former 候选掩码
  → 候选图：9 维节点特征 + 8 维成对几何特征
  → 两层图消息传递
  → 有效性 / 拓扑 / 成对竞争 / 基数预测
  → MILP 精确子集选择
  → 最终实例集合
  → 病例级统计、bootstrap、LOCO 与运行回执
```

完整流程和代码入口见 [端到端流程](docs/02_端到端流程.md)。

## 这份仓库能看到什么

| 能力 | 仓库中的证据 |
|---|---|
| 将视觉问题转成结构化预测问题 | 候选图、节点/边特征和最终子集定义 |
| 图模型与集合建模 | 图路径、节点路径、四类预测头和集合池化 |
| 优化建模 | 带基数与候选竞争约束的 MILP 选择器 |
| 实验设计 | 病例隔离划分、随机种子、bootstrap、LOCO 和非补偿判定 |
| 可复现工程 | 冻结协议、计算清单、运行回执和 SHA-256 清单 |
| 代码质量 | 可安装包、统一检查入口、端到端示例和核心模块测试 |
| 科学判断 | 源域、ROBUST-MIPS 与 Endoscapes 分开解释，机制诊断不越界 |

## 快速运行

已配置环境时，直接运行：

```powershell
python scripts\check_all.py
```

也可以逐项检查：

```powershell
python scripts\verify_release.py
python scripts\smoke_test.py
python -m cmig_qgraph
python -m pytest -q
```

端到端示例使用三个合成候选，不读取论文数据。它会运行候选图构造、图路径、节点路径和 MILP 选择器。

## 论文证据范围

正式比较是完整关系路径与节点特征匹配路径，即 `complete relational path` 对 `node-feature-matched path`。这个比较识别完整路径效果，不分离关系特征、消息传递、基数预测或模型容量的独立因果作用。

- 密封源域测试：22 个病例，承担主要正式比较；
- ROBUST-MIPS：三个随机种子均满足完整判定条件，支持该域的直接迁移；
- Endoscapes：10 个病例、74 帧，只有一个随机种子满足完整判定条件，不能概括为稳定迁移；
- 机制诊断：只用于补充解释和失败模式分析。

数字、估计量和允许结论见 [结果与边界](docs/05_结果与边界.md)。
