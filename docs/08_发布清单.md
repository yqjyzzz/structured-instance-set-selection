# 发布清单

- [x] 全体作者确认仓库内容；
- [x] 选择并加入 MIT 软件许可证；
- [x] 填写 `CITATION.cff` 中的公共仓库地址；
- [x] 确认协议和运行回执的公开范围；
- [x] 确认仓库不含临床图像、掩码、候选缓存、模型权重和私有路径；
- [x] 运行 `python scripts/check_all.py`；
- [ ] 在干净虚拟环境中执行安装测试；
- [x] 核对 `SOURCE_MANIFEST.sha256`；
- [x] 将公共仓库地址写入论文数据与代码声明。

当前目录对应公开软件版本 `0.1.0`。每次发布内容变化后仍需重新执行干净环境安装、完整检查与清单核对。
