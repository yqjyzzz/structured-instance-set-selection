# 工程质量

## 目录职责

科学代码、协议、运行工具、结果说明和测试分开存放。冻结协议位于 `protocol/`，模型位于 `src/`，演示与检查入口位于 `scripts/`，避免把实验回执和实现代码混在同一目录。

## 可安装与可运行

仓库采用 `src` 布局，并通过 `pyproject.toml` 声明依赖、开发工具和命令行入口。安装后可运行：

```powershell
python -m structured_instance_selection
structured-instance-demo
```

## 自动化检查

`scripts/check_all.py` 提供统一检查入口。当前测试覆盖：

- 必需文件和协议 JSON；
- 病例划分字段；
- 本机绝对路径泄露；
- 节点和边特征维度；
- 图路径与节点路径前向传播；
- MILP 选择结果与基数约束。

## 完整性

`SOURCE_MANIFEST.sha256` 记录发布包文件哈希。协议目录保留冻结协议、计算清单和预检回执，便于核对代码、环境与实验设计。

## 保留原始科学代码

核心训练文件来自冻结执行包。仓库新增的安装入口、示例和测试放在独立文件中，避免为了展示效果改写已登记的科学实现。

## 发布前检查

- 代码许可证已确定为 MIT；
- 确认哪些运行回执可以公开；
- 在干净环境中执行一次安装测试；
- 获得授权后补充公开数据获取说明或下载脚本。
