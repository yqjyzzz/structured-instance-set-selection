# 项目讲解

## 90 秒版本

> 这个项目处理实例分割候选如何组成最终实例集合。Mask2Former 输出候选掩码后，我把候选表示为图：节点描述候选本身，边描述候选之间的几何关系。图模型联合预测候选有效性、拓扑状态、候选竞争和实例数量，MILP 再根据这些结果选择最终子集。实验按病例划分，使用 bootstrap、LOCO 和冻结判定条件，并分别报告源域、ROBUST-MIPS 和 Endoscapes。当前证据支持完整路径效果，但不把提升归因于某个单独图组件。

## 五分钟顺序

1. 用 `02_端到端流程.md` 解释输入和数据流；
2. 打开 `rid_qgraph_core.py`，定位图构造、两条模型路径和 MILP；
3. 运行 `python scripts/check_all.py`；
4. 用冻结协议说明病例划分、随机种子和统计单位；
5. 用 `05_结果与边界.md` 解释三类数据域和机制边界。

## 常见问题

### 基数预测读取什么？

它读取消息传递后的候选状态。有效候选经过均值与最大值池化，形成 128 维集合表示，再输出 11 个基数类别。

### MILP 负责什么？

它把候选有效性、成对竞争、可选状态和预测基数组合成一个精确选择问题，并返回最终候选子集和求解状态。

### 为什么不能说关系信息造成了提升？

正式图路径同时增加关系处理和参数容量。现有比较识别完整路径效果，没有分离关系本身的独立作用。

### 为什么 Endoscapes 结论更弱？

该域只有一个随机种子满足完整判定条件，另外两个没有满足全部性能与安全要求，因此不能写成稳定迁移。
