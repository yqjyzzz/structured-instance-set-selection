# 实验复现

## 环境

最小依赖包括 Python 3.10、NumPy、SciPy 和 PyTorch。开发依赖包括 pytest 与 Ruff。原始运行环境记录在 `protocol/QGRAPH_A2_COMPUTE_MANIFEST.json`，其中包含 PyTorch、CUDA 和 GPU 信息。

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e ".[dev]"
```

## 本地检查

```powershell
python scripts\check_all.py
```

统一入口依次运行仓库结构校验、端到端冒烟测试和 pytest。它不读取论文数据，也不训练模型。

## 完整实验所需资产

完整训练和评估还需要：

- 数据提供方授权的数据；
- 与冻结协议一致的候选缓存；
- 对应的模型权重或重新训练条件；
- 可写的输出目录；
- 运行回执、输入哈希和求解器状态记录。

这些大文件应存放在仓库外部，通过命令行参数传入。

## 冻结设置

- 源域开发集：18 个病例、4,246 帧；
- 发现随机种子：17、23、41；
- 外层折：1 至 6；
- 图模型随机种子：101、103、107；
- 训练轮数：30；
- 优化器：AdamW；
- 学习率：0.001；
- 权重衰减：0.0001；
- 病例级 bootstrap：10,000 次，随机种子 20260729；
- 统计检查：Holm 校正、LOCO、Union-Dice、空帧激活和求解器状态。

## 复现边界

改变数据划分、阈值、统计单位或估计量会得到新的实验，不能沿用论文的冻结判定。源域测试、ROBUST-MIPS 和 Endoscapes 也必须分别运行和解释。
